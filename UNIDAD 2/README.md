# PROYECTO U2 y Tareas Bonus
- Sistema de Enrutamiento para tiendas de autoservicio (Proyecto)
# Objetivo General del proyecto
Su objetivo principal para esta tarea es diseñar e implementar una solución computacional
que utilice algoritmos heurísticos, específicamente Recocido simulado o Búsqueda tabú.
Esta solución debe tener como objetivo optimizar las rutas de distribución de productos de 
abarrotes desde los centros de distribución hasta varias sucursales de una cadena de restaurantes ubicada en Culiacán, Sinaloa. 
Al hacer esto, ayudará a mejorar la eficiencia logística y reducir los costos operativos.
